01 · División entera y resto
int total = 125;
int grupos = total / 50;   // 2
int sobran = total % 50;   // 25
int unidades = 472 % 10;   // 2

Con dos int, / descarta los decimales y % da el resto. Es la clave para tiempos, cambio y cifras.

02 · Constantes
final double IVA = 0.21;
final int SEG_HORA = 3600;
double iva = precio * IVA;

Con final el valor no puede cambiar. Por convenio, se escriben en MAYÚSCULAS.

03 · La clase Math
double r = Math.sqrt(25);      // 5.0
double c = Math.pow(3, 2);     // 9.0
double p = Math.PI;

Raíces, potencias y π sin programarlos tú. Devuelven double.

04 · Cuidado con los tipos
double f1 = 9 / 5;       // 1.0 ¡ojo!
double f2 = 9.0 / 5;     // 1.8
System.out.printf("%.2f%n", f2);

Si los dos operandos son enteros, la división es entera. Usa printf para fijar los decimales.

Todos los retos se resuelven sin if ni bucles: solo con sentencias simples. Si ya conoces las condicionales, resiste la tentación.
