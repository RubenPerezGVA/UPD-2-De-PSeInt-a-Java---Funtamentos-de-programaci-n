01 · Estructura
public class Main {
  public static void main(String[] args) {
    // Instrucciones
  }
}

El punto de entrada habitual es main. Sustituye Main por el nombre de tu archivo si corresponde.

02 · Variables y operadores
int edad = 18;
double precio = 12.5;
String nombre = "Ana";
double total = precio * 1.21;

Tipos básicos, asignación y operaciones + − * / %.

03 · Leer con Scanner
import java.util.Scanner;
Scanner teclado = new Scanner(System.in);
int unidades = teclado.nextInt();
double precio = teclado.nextDouble();

Para nombres completos, nextLine(). También se admite BufferedReader.

04 · Mostrar resultados
System.out.println("Total: " + total);
System.out.printf("%.2f", total);

Escribe mensajes claros, comprueba las operaciones con datos distintos y evita dividir entre cero.
