02 / APOYO

Guía rápida de Java

Teoría completa en PDF ↗
01 · Leer texto y números
String nombre = teclado.nextLine();
int horas = teclado.nextInt();
double precio = teclado.nextDouble();

Lee primero el texto con nextLine(): tras un nextInt() queda un salto de línea pendiente.

02 · Operadores y unarios
float r = a % b;   // resto
a++;               // a = a + 1
b--;               // b = b - 1

% da el resto de la división. ++ y -- suman o restan 1 a la propia variable.

03 · Relacionales y boolean
boolean iguales  = a == b;
boolean distintos = a != b;
boolean mayor     = a >= b;

Comparar da true o false. Operadores: == != > < >= <=.

04 · Constantes y Math
final double MILLA = 1609.344;
double v = 4.0 / 3 * Math.PI * Math.pow(r, 3);

Con final el valor no cambia. Cuidado: 4 / 3 con enteros vale 1; usa 4.0 / 3.
